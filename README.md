# Knowledge-Centric Enterprise Architecture (KCEA)

## The Enterprise as a Knowledge Network

This repository contains the white paper:

**Knowledge-Centric Enterprise Architecture (KCEA)**

### Abstract

KCEA explores the hypothesis that enterprises can be organized around explicit knowledge networks rather than applications. In this model, knowledge becomes the primary system of record while applications, services, and AI function as replaceable execution and reasoning layers.
